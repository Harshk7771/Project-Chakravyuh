**Project Chakravyuh** is an enterprise-grade, fully autonomous Security Operations Center (SOC) platform built on 100% open-source technologies. Named after the legendary multi-layered military formation from the Mahabharata, it delivers concentric layers of detection, monitoring, and automated response.

## ⚡ Quick Deploy

```bash
git clone https://github.com/your-org/chakravyuh.git
cd chakravyuh
cp .env.example .env
docker compose up -d
```

Access dashboard at `http://localhost:8080`

## 🛡 Capabilities

| Module | Description |
